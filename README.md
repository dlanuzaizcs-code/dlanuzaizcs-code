### [Home Cyber Defense Lab — Public Showcase](https://github.com/dlanuzaizcs-code/soc-homelab-showcase)

An independently built and documented defensive-security homelab with practical coverage of:

The public showcase uses synthetic examples and sanitized documentation. Operational infrastructure and sensitive configuration remain private.

### [Windows USB Forensics & Explainable Anomaly Detection — Master's Thesis](https://github.com/dlanuzaizcs-code/windows-usb-forensics)

A completed Windows 11 forensic research prototype developed with **Python, PyQt6 and SQLite**, including:

- **Multi-source evidence:** Windows Registry, Event Logs and SetupAPI correlation to reconstruct USB activity.
- **Behavior analysis:** explainable anomaly scores for unusual devices, connection times and multivariate deviations.
- **Defensive response:** configurable modes, trusted-device policy and TOTP-based reactivation.
- **Validation:** **98/98 automated tests passed on Windows** (30 October 2026). The thesis reports **ROC AUC ≈ 0.87** on a 50-session **synthetic** overlapping-class experiment; this is not a production detection benchmark.

The repository contains the application source, tests, technical documentation and selected sanitized figures.
