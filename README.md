## Featured project

### [Home Cyber Defense Lab — Public Showcase](https://github.com/dlanuzaizcs-code/soc-homelab-showcase)

A curated, sanitized walkthrough of my personal cybersecurity lab. It covers:

- **Endpoint detection:** Windows, Sysmon and Wazuh; process and PowerShell telemetry, benign validation tests, and analysis workflows.
- **Network visibility:** Suricata, managed switching, traffic mirroring, JSON events, and log-retention policies.
- **Linux infrastructure:** Raspberry Pi 5, Debian, Docker, Tailscale, and self-hosted services.
- **Resilience:** scheduled backups, integrity checks, monitoring, and a verified file-restore exercise.
- **Digital forensics:** a Master's thesis project exploring USB device activity in Windows using Python and SQLite.

The public repository contains **synthetic examples and sanitized documentation**. The operational lab and sensitive configurations remain private.
